# Wayside v0.0.6 - Wood Processing & Task Stages

### 新增（Added）
- 新增 NPC 任务阶段系统：`COLLECTING → CRAFTING → COMPLETED`。
- 新增自动木板合成行为，使用 Minecraft 原版合成配方。
- 支持不同种类原木加工成对应木板。
- 新增任务阶段的 NBT 持久化。
- 新增掉落物拾取失败冷却机制，避免 NPC 反复尝试不可达目标。

### 改进（Improved）
- NPC 收集足够原木后，自动切换至加工阶段。
- 合成前检查背包容量，防止材料或产物丢失。
- 加工完成后正确终止任务，避免重复采集。
- 优化不可达掉落物的目标选择与失败恢复。

### 测试（Tested）
- 自动采集与木板加工。
- 不同木材的配方匹配。
- 背包满载时的合成保护。
- 不可达掉落物的冷却与重新尝试。
- 任务阶段及背包数据的存档恢复。
