# Wayside v0.0.5 — Resource Collection & Basic Needs

本版本实现了 NPC 的基础物品存储、自动拾取和资源需求机制，初步形成了自主资源获取循环。

### 新增功能（Added）

- 为 NPC 添加独立的 9 格背包，使用 `SimpleContainer` 存储物品。
- 实现附近掉落物的自动拾取与主动寻路收集。
- 添加基础资源需求判断：NPC 在原木储备不足 16 个时主动采集，达到目标数量后停止寻找原木和掉落物。
- 支持多种原木的统一数量统计。
- 实现 NPC 背包的 NBT 持久化，保存并重新加载世界后仍能保留物品。

### 改进（Changed）

- 扩展 `NpcFindBlockGoal`，根据资源需求决定是否搜索原木。
- 新增 `NpcCollectItemGoal`，负责搜索掉落物、寻路以及近距离移动。
- 改进拾取时的移动控制，减少寻路提前结束造成的漏捡问题。
- 添加资源数量调试信息，便于观察 NPC 的背包状态。

### 测试（Tested）

- 验证物品存入背包及不同 NPC 背包的独立性。
- 验证 NPC 自动寻找、靠近并拾取掉落物。
- 验证原木达到 16 个后停止采集与主动收集。
- 验证原木被消耗后能够重新开始采集，形成重复运行的资源获取循环。
- 验证退出并重新加载世界后，NPC 背包内容能够正确恢复。

### 已知问题（Known Issues）

- NPC 接近掉落物时偶尔会出现短暂打转。
- 目前仅支持基于原木储备数量的简单需求判断，尚未实现通用需求调度系统。
- 尚未实现物品合成、工具使用和建造。

### 下一步（Planned）

- 实现基础物品合成，让 NPC 能够主动消耗收集到的原木。
- 逐步扩展资源需求与行为执行机制。
