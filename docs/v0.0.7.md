# Wayside v0.0.7


### 主要更新

**1. 重构 NPC 任务系统**
- 引入 `NpcTask` 与 `NpcAction` 接口，分离任务管理和具体动作执行。
- 新增 `NpcTaskRunner`，统一管理任务执行、暂停、恢复、取消和失败状态。
- 新增 `TaskSequence`，支持多个子任务按顺序执行。
- 引入 `NpcTaskTypes`，统一管理任务类型及其创建方式。

**2. 模块化基础行为**
- 将移动、方块破坏、物品拾取和合成拆分为独立 Action。
- 重构资源采集流程，支持根据目标条件复用采集逻辑。
- 将失败目标冷却记录抽象为 `FailureMemory`。
- 支持通过临时移动任务打断当前工作，并在结束后恢复原任务。

**3. 新增材料规划与合成系统**
- 引入 `MaterialPlanner` 与 `MaterialPlan`，根据物品需求、现有库存和 Minecraft 原版配方制定材料获取计划。
- 新增 `SupplyMaterialsTask`，组合资源采集和配方合成，满足指定材料需求。
- 支持多步骤合成及材料缺口计算。
- 增加合成原料、背包空间和工作台条件检查。

**4. 存档与兼容性**
- 支持保存和恢复任务类型、执行进度及运行状态。
- 保留对 v0.0.6 部分旧任务存档数据的兼容处理。

### 当前限制

- 自动采集仍以原木资源为主，通用材料任务目前仅支持自动补充橡木原木。
- 任务自动决策与调度系统尚未实现。
- 建筑材料仓储、运输及实际建造流程尚未接入。

### 测试

已完成现有 NPC 采集、拾取、合成及任务执行流程的功能测试。
